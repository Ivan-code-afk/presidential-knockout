# PRESIDENTIAL KNOCKOUT

Пиксельный пародийный 2D-файтинг в браузере: президенты США дерутся за «пятый срок». Вся игра на английском.
Неофициальная пародия, все персонажи — шаржи.

## Как запустить

Открыть `index.html` в браузере или выложить папку на GitHub Pages как есть. Сборка не нужна: всё статическое.

## Ветки

- `main` — проверенная версия, её показывает GitHub Pages.
- `dev` — рабочая ветка, сюда идут все правки. В `main` переносятся только проверенные версии.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html`, `style.css` | Страница, холст 1280×720, сенсорные кнопки |
| `game.js` | Движок: бой, бот, меню, аркада, рисование |
| `data.js` | Всё, что правится без программирования: бойцы, параметры, приёмы, тексты фаталити и концовок, арены, аркада |
| `sprites.js` | Список спрайтов бойцов (пока пусто — рисуются заглушки) |
| `assets/` | Картинки: `sprites/`, `arenas/`, `portraits/` |

## Управление

| | 1 игрок | 2 игрока: 1P | 2 игрока: 2P |
|---|---|---|---|
| Ходьба | ← → | A D | ← → |
| Прыжок | ↑ / Пробел | W | ↑ |
| Присед и блок снизу | ↓ | S | ↓ |
| Рука / нога / спец | A S D (или J K L) | F G H | J K L |
| SUPER (при полной шкале) | A+S или F | T | I |

- Блок стоя: держать направление **от** соперника. Он держит удары рукой, удары сверху и снаряды.
- Удар рукой идёт высоко: от него можно уйти в присед. Удар ногой идёт низко: его держит только присед.
- Удар ногой в прыжке бьёт сверху: присед от него не спасает.
- Esc / P — пауза. На телефоне — джойстик слева и кнопки справа.

## Аркада

7 боёв: два на ярмарках, два на больших аренах, два в третьем туре (ток-шоу, ужин корреспондентов, Конгресс) и финал против Мистера Рейтинга в Овальном кабинете.
На половине здоровья босса кабинет превращается в его студию. После победы открывается Мистер Рейтинг.

## Отладка

В консоли браузера доступен `PK`: `PK.botVsBot("bush", "trump", "detroit")` запускает бой бот против бота.
